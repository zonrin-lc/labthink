# labthink-gravimetric-ppt

济南兰光（Labthink）重量分析产品行业解决方案PPT制作Skill（专业版）。面向"给定行业 → 产出一份对外解决方案PPT"的完整流程。

## 产品范围

恒为三系列产品：
- **C870** 集成式干燥失重检测系统（干燥失重/水分）
- **C860** 集成式灼烧残渣检测系统（炽灼残渣/灰分）
- **C840** 集成式蒸发残渣检测系统（蒸发残渣/不挥发物/总迁移量）

## 功能特性

- **行业自动匹配**：自动匹配色调风格/行业术语/行业标准/行业困境与政策
- **四套已验证版式**：
  - 版式A（默认）：深蓝金，用户定稿V1.4风格，32页五幕
  - 版式B：墨绿金，豆包风格，带英文副标题
  - 版式C：米白深蓝金，Kimi风格，每页页眉导航条
  - 版式D：蓝青金，WorkBuddy风格，37页六章
- **12个行业知识文件**：医药/食品/化工/环境/冶金/建材/橡胶/塑料/烟草/饲料/造纸/能源
- **49家医药客户Logo资产**：内置logo墙模板与排版脚本
- **飞书知识库检索**：自动读取行业标准表、检测报告库
- **跨行业术语对照**：避免"炽灼残渣/灼烧残渣"、"总迁移量/蒸发残渣"等术语混用

## 适用场景

- "做一份XX行业的重量分析/水分/灰分/灼烧残渣/蒸发残渣解决方案PPT"
- "按行业出方案"
- "兰光行业方案PPT"

## 安装方式

### 方式一：单独安装（推荐）

双击运行仓库根目录的 `install-labthink-gravimetric-ppt.bat`

### 方式二：一键安装全部

双击运行仓库根目录的 `install-all.bat`，选择安装全部或指定Skill

### 方式三：豆包自动安装

复制这句话发给豆包：
```
帮我安装labthink-gravimetric-ppt skill：
1. 用git克隆仓库 https://github.com/zonrin-lc/labthink.git 到 D:\labthink
2. 运行 install-labthink-gravimetric-ppt.bat 安装
3. 告诉我安装结果
```

## 使用方法

1. 重启豆包
2. 输入"做一份XX行业的重量分析解决方案PPT"
3. 选择版式（默认A，可指定B/C/D）
4. 按流程：定行业 → 行业知识检索 → 内容稿 → 事实审查 → 客户墙 → 幻灯片制作 → 终检交付

## 硬约束（不可违反）

1. 产品名称不可改：C840集成式蒸发残渣检测系统、C860集成式灼烧残渣检测系统、C870集成式干燥失重检测系统
2. 四套版式元素不可混用，选定后全篇一致
3. "关于Labthink公司介绍页、资质与荣誉页、产品体系架构页"三页一律复用用户V1.4原版（仅允许改色调）
4. 客户墙必须用真实客户logo，必须先询问用户提供49家客户名单

## 依赖环境

- 豆包专业版
- 飞书连接器授权（读取行业标准表、检测报告库）
- Python 3.x + lxml库

## 与 industry-solution-ppt 的区别

| 定位 | 通用行业方案PPT | 兰光重量分析产品专用 |
