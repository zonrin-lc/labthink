# 设计系统：四套版式 + 行业色调映射

四套版式均由真实成稿验证。**默认版式 A**；与用户确认后切换。四套元素不可混用；三个固定页（见 locked-pages.md）无论选哪套都从用户 V1.4 抽取复用，仅换色。

画布统一 13.33×7.5 in（16:9）。字体三件套统一：标题 微软雅黑 加粗、正文 微软雅黑/Light、数字英文 Calibri、页脚小注 思源黑体。

## 行业 → 主色映射（开工先定）

| 行业 | 主色（深） | 强调色 | 辅助/底色 | 气质 |

| 食品/食品接触材料 | `#1F5C3D` 深绿 | `#E8830C` 暖橙 | 米白 `#FAF6EE` | 安全、活力 |
| 环境/水质/大气 | `#0F4C5C` 青蓝 | `#2A9D8F` 青绿 | 浅青白 `#F0F6F5` | 洁净、环保 |
| 冶金/钢铁/有色 | `#2B2D42` 钢灰蓝 | `#D97706` 铁橙 | `#EDF0F3` | 厚重、精密 |
| 建材/水泥/陶瓷/玻璃 | `#37474F` 水泥灰 | `#C9A227` 陶金 | `#F5F3EE` | 质朴、稳健 |
| 化工/化学试剂/涂料 | `#1E3A5F` 工业蓝 | `#0EA5A5` 青 | `#F1F5F9` | 理性、规范 |
| 橡胶/塑料/高分子 | `#1F2937` 深炭 | `#E11D48` 品红（仅小面积） | `#F3F4F6` | 现代、材料感 |
| 造纸/纺织/皮革/木材 | `#5D4037` 棕 | `#A16207` 木金 | `#FAF7F2` | 自然、温度 |

## 版式 A —— 用户定稿 V1.4（默认主，32页五幕）

**配色**：
- 深主色（章节页/封面/结尾底）：`#040505`
- 强调金：`#F5B700` / `#FCC800` / `#FFC20F`（数字高亮、装饰条、关键词）
- 深蓝次级：`#0A2540`、`#0D57A8`
- 正文：`#1F2329`；次要 `#404040`/`#666666`
- 卡片底 `#F2F2F2`；描边 `#D9D9D9`；淡金底 `#FFF2CC`/`#F3EBC9`

**版式特征**：
- 章节分隔页极简：深底 + 白色大标题 + 金色短装饰（P3/P6/P10/P25/P29）。
- 内容页白底：顶部 22–24pt 标题 + 金色编号/短线；内容用浅灰圆角卡片承载；关键数字金色加粗。
- 困境页四象限卡片；政策页三列卡片+页脚来源；产品页实拍图+双版本参数(H高配/M标准)；流程页线性流程图（空杯恒重→检测→恒重差<0.3mg）。
- 目录页五幕（01–05）。

## 版式 B —— 豆包版（32页，墨绿金）

**配色**：深墨绿 `#0F3D3E` + 古金 `#C9A961`。

**版式特征**：
- 章节页带大编号 + 中文大标题 + 英文副标题（PREDICAMENT & POLICY / ABOUT LABTHINK 等）+ 一句小字定位。
- 内容页用深绿主标题 + 金色编号圆点 + 浅卡片；困境页 01–04 编号卡片；共性特点拆 4 页（精准/高效/合规/安全各一页，带大数字如 400%）。
- 比 A 更"出版级"，每页英文眉题，留白讲究。

---

## 版式 C —— Kimi 版（32页，米白深蓝金）

**配色**：深靛 `#131B36` + 金 `#F5B700` + 米白 `#EDEAE0`/`#D9D4C7`。

**版式特征**：
- 内容页带统一页眉条：左"LABTHINK · XX解决方案"、中"第X章 · 章节名"、右"集成式检测系统解决方案"；米白底。
- 章节页大编号 CHAPTER 0X + 中英标题 + 一句副线。
- 卡片用米白/浅棕描边，金色仅做编号与分隔；流程页用米白底节点。

---

## 版式 D —— WorkBuddy 版（37页六章，蓝青金）

**配色**：深蓝 `#0F233C` + 青 `#00A0B0` + 金 `#F5B700` + 浅蓝白 `#F5F8FC` + 分隔 `#E1E8F0`。

**版式特征**：
- 六章结构（多了"市场趋势/方案总览"与"产品家族"拆分、传统vs自动化对比页、末页技术参数附录）。
- 每页英文小标签（PAIN POINTS/POLICY BACKGROUND/SYSTEM ARCHITECTURE…）+ 中文大标题；青绿色做模块标签、金色做大数字。
- 适合需要市场数据、选型对比、完整参数附录的讲法。

## 通用版式规则（四套共用）

- 每页一个结论式标题；正文短句列表；政策/数据/来源标注页脚小注。
- 数据一律表格化（平行样/RD值/判定），表头深底白字，关键结果强调色高亮。
- 连续两页避免相同骨架；产品页实拍图优先；流程页用箭头连接节点。
- 每页 `<note>` 写 3–5 句可照读讲稿；串讲词 100–150 字。
