**公司简介**：
成立于 1989 年，是国内最早从事包装检测仪器研发制造的企业之一，开创中国包装检测事业先河。公司实现了全球化布局，在美国波士顿、德国法兰克福、马来西亚吉隆坡、阿联酋迪拜设立了四大海外中心，是行业内仅有的实现全球化布局的中国包装检测仪器制造企业。

1. **自主创新力**：以高占比科研投入驱动自主创新，科研投入年均占比10%左右，年均投入经费近2000万元。
2. **科研平台**：CNAS认证实验室成立26年，覆盖53个种类、276个检测项目，配备设备160余台套。
3. **标准话语权**：主持/参与制（修）订国家标准23项、行业标准8项；承担国家及省级科研项目近30项。

## 固定页 3：产品体系架构页（第三章第二页）

**标题**：产品体系架构

**三层架构（自顶向下）**：

**① 数据层 — 合规安全**
- 符合 GMP 数据可追溯要求：多级权限 / 电子签名 / 审计追踪 / 原始数据直传
- 双仓完全独立物理隔离

**② 执行层 — 硬件集成仓**
- 机械手自动化跨仓运转
- 称量仓：德国进口高精度天平，恒温恒湿、恒重称量
- 全密闭试验仓：12–36工位批量连续处理，加热/灼烧/蒸发/干燥冷却；外置液冷、外置加酸
- 安全模块

**③ 控制层 — 智能主机**
- 温度控制：升温速率控制 / 液冷循环控制 / 恒温精密控制
- 称量控制：自动内校 / 自动去皮 / 可视化实时读数
- 辅助控制：自动加酸 / 氮气循环 / 试剂回收
- 交互与安全：医疗级触控屏 / 网口远程控制 / 多传感器声光报警
- 无人值守 overnight 运行

**底部六模块标签**（与"核心组成模块页"呼应）：机械手模块 / 温控模块 / 称量模块 / 辅助模块 / 安全模块 / 软件模块。
