# 内容稿事实审查清单（行业无关通用版）

## 审查维度（逐条核验）

1. **虚构/无中生有**：材料中不存在的产品、客户、数据、荣誉、机构
2. **事实性错误**：数据（数量、时间、口径、比例）、人名、机构名、产品型号、标准号、结论与材料不符
3. **前后矛盾**：同一事实在不同页面/章节表述不一致（含两版材料口径冲突）
4. **缺乏依据**：无材料出处支撑的定性表述（"领先""唯一""最""最高"等）

## 每条问题的输出格式

```
- 位置：页码/章节/具体句子
- 问题：具体描述（是什么错误）
- 依据：引用参考材料原文（文件 + 页码 + 原句）
- 建议：修改后的准确表述
- 无法在材料中找到出处的条目，单独标注"未找到出处"
```

审查后未发现问题也要明确说明，并写明检查范围与覆盖文件。

## 通用踩坑类型（各行业适用）

| 类型 | 检查要点 | 处理 |
|---|---|---|
| 术语 | 规范术语 vs 俗称/口语（如"炽灼残渣"非"灼烧残渣"） | 以该行业权威标准/法规术语为准，见 `references/industry/` 对应文件 |
| 标准号 | 标准号新旧版本、年份错误 | 核对现行有效版本 |
| 数据口径 | 数量、杯次、批次、比例的口径不一致 | 回到原始明细逐条核对 |
| 夸大词 | "行业领先""唯一""最"等无出处表述 | 有出处保留，无出处删除或限定 |
| 名称 | 企业客户名、机构全称被简化/加字 | 客户名按用户要求模糊化；机构全称保留原名 |
| 属地 | 擅自标注到市级/自造城市 | 只到省一级，无信息不标注（用户偏好） |
| 时效 | 成立年限、市占率、政策版本随时效变化 | 按当前日期重算，以最新材料/用户确认为准 |

## 核验动作

- 汇总、合计、换算、比例用计算工具复核，禁止心算
- 同一数据跨产物（内容稿/PPT/报告）并排核对
- 外部事实（法规、标准、政策）用可信来源搜索核验，区分"已查证"与"一方称"，并标注来源（文件/会议/日期）
- 行业专属踩坑案例见 `references/industry/` 各行业知识文件
