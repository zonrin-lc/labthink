# 文案措辞与合规规范

## 客户视角（对客户讲 vs 对投资人讲）

| 场景 | 不合适 | 合适 |
|---|---|---|
| 讲知识产权 | "构筑核心技术知识产权壁垒" | "保障核心技术自主可控、持续迭代" |
| 讲资质荣誉 | 平铺堆砌 | 按"官方资质认定 / 科技奖项 / 检测公信力与行业认可"分类，**检测公信力放前**（B2B客户最看重数据公信力） |
| 讲专利 | 只报数量 | 数量 + 对客户的价值（供货有保障、技术不依赖外部） |

原则：对采购方讲"你的供货和技术有保障"，不讲"我们设了墙"。

## 企业客户名模糊化（用户明确要求）

- 涉及实际客户案例时，不直接用企业名称；改为"行业 + 规模/区域特征"的模糊表述。
- V1.4定稿实例：
  - 四川科伦药业 → "某大型化学药企QC实验室"
  - 杭州中美华东制药 → "华东某综合制药企业"
  - 东阿阿胶 → "国内某知名胶类中药企业"
- 只有用户确认可点名时才使用全称。
- 模糊化后仍保留关键数据（检测项目、杯次、平行差、RD值等），数据本身不变。

## 来源标注规范

- 政策、法规、数据、引用观点**必须标注来源**（发文部门/文件名称/会议名称/日期），页面和备注都要有。
- 例："来源：国家工业和信息化部等七部门联合印发《医药工业数智化转型实施方案（2025—2030年）》""来源：国务院政策例行吹风会，2026年4月15日"。

## 属地标注规范（用户偏好，强制）

- 属地信息只标注到省一级（如"山东省"），不标注市级。
- 无城市信息时不得自行标注城市。
- 不加序号。
- 机构全称（如"包装性能检测济南市工程研究中心"）保留原名不视为违规。

## 数字口径

- 每个数字必须有来源（材料文件+页码）；同一数据跨产物并排核对。
- 汇总、换算、比例用计算工具，禁止心算。
- 无法核实的数字标"待补充"并写明口径，不编默认值。
- 注意两版材料口径冲突（如药企客户数"2200+" vs "1000+"），以最新版或用户确认为准，不得自行沿用旧值。

## 资质荣誉分类模板（可直接用）

1. 企业资质认定：国家高新技术企业、单项冠军、专精特新、纳税信用、ISO三体系
2. 行业身份与话语权：标准制定参与、行业协会成员、行业组织主办/专家组成员
3. 科技奖项：国家级/省级科技进步奖、专利奖等
