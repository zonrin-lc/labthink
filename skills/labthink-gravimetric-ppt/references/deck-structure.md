# 行业解决方案 PPT 结构模板（五幕）

沉淀自用户定稿 V1.4（32页）。换行业只换内容与色，骨架不变。**三个固定页（★）位置与内容见 locked-pages.md，只允许改色。**

## 五幕结构

**第一幕 困境与政策**
1. 封面：方案名称 + 副题（聚焦某细分场景）+ 关键词（精准/高效/合规/安全）+ 公司名 + 年份
2. 目录：五幕（困境与政策 / 关于公司 / 自动化检测产品体系 / 应用场景与实证 / 服务支持）
3. 章节分隔页：第一幕（深底 + 大标题）
4. 行业困境：传统重量分析在**本行业**的四维困境（效率/误差/风险/合规，带本行业数字，标注依据）
5. 政策背景：新规 + 监管加严 + 数智化转型，**每条标注发文部门/日期**

**第二幕 关于公司**
6. 章节分隔页：第二幕
7. ★**公司介绍页（固定）**：始于1989 / 37年 / 110+国家 / 70%市占 + 四栏实力（见 locked-pages）
8. ★**资质与荣誉页（固定）**：科技奖项 / 行业身份话语权 / 官方资质三段式
9. **49 家客户墙页**：标题"XX行业服务客户——1000+XX企业的共同选择"，按 industry-logo-wall.md 出 49 家

**第三幕 自动化检测产品体系**
10. 章节分隔页：第三幕
11. 产品总览：三系列 × 检测项目 × **本行业标准映射**（一页看懂）
12. ★**产品体系架构页（固定）**：数据层/执行层/控制层三层 + 六模块（见 locked-pages）
13. 核心组成模块：六大模块协同
14–16. 每个产品系列一页：实拍图 + 双版本参数(H高配/M标准) + 技术特点 + 本行业适用对象
17–19. 每个系列一页工作流程图：以本行业标准方法为例（空杯恒重→检测→恒重差<0.3mg）

**第四幕 应用场景与实证**
20. 章节分隔页：第四幕
21–22. 实证案例：**本行业有真实案例取 2 个；没有就补 1 个通用模糊化案例**（标注待替换）。每例 = 客户（模糊化）+ 设备组合 + 检测数据表格（平行1/2/3、RD值、判定）+ 客户价值
23. 共性特点页（可拆多页）：精准/高效/合规/安全四维

**第五幕 服务支持**
24. 章节分隔页：第五幕
25. 实施建议：三步走（选型/部署/验证），含设备参数与验证要求；提供样品免费比对检测
26. 服务与支持：技术支持/售后/软件升级、全球四大中心、7×24
27. 结尾：行动号召 + 联系方式（济南兰光机电技术有限公司 · 济南市无影山路144号 · +86 0531 8506 8566 · www.labthink.com）

> 版式 B/D 可在第一幕与第三幕间加"市场趋势/传统vs自动化对比"页，末页加"产品完整参数附录"；版式 A/C 保持五幕 32 页量级。

## 页面设计要点

- 每幕有章节分隔页；每页一个结论式标题，正文短句列表，数据高亮。
- 连续两页避免相同骨架；数据类用表格/对比，流程类用流程图，产品页用实拍图。
- 政策/标准/来源必须标注出处；标准号用飞书知识库核对的现行版；客户名按 copywriting.md 模糊化。
- 每页 `<note>` 写 3–5 句可照读讲稿；结尾深色背景收束 + 联系方式。
