# 行业解决方案PPT结构模板（五幕）

沉淀自兰光集成式检测系统（制药质量控制）方案 V1.5（用户定稿版，32页，元素已解组优化布局）。页数按内容量调整。

> **复用类型说明**：每页标注 `[通用]`/`[半通用]`/`[行业专属]`，对应 SKILL.md 0.1 节模板复用矩阵。模式A（模板复用）下，`[通用]`页直接复用，`[半通用]`页替换行业要素，`[行业专属]`页必须重写。

## 五幕结构

### 第一幕 困境与政策

1. **封面** `[通用]` — 方案名称 + 副题（聚焦某细分场景）+ 关键词（精准/高效/合规/安全等）+ 公司名 + 日期
   - 素材来源：公司材料
   - 模式A处理：仅替换标题中的行业名和副标题关键词

2. **目录** `[通用]` — 五幕结构（困境与政策 / 关于公司 / 自动化检测产品体系 / 应用场景与实证 / 服务支持）
   - 素材来源：固定结构
   - 模式A处理：直接复用
   - **修改注意**：备注中"医药行业服务基础""四个医药行业典型场景"等表述需替换为目标行业

3. **章节分隔页** `[行业专属]` — 每幕开篇一页（背景图 + 大标题）
   - 素材来源：固定版式
   - 模式A处理：替换章节标题中的行业名

4. **行业困境** `[行业专属]` — 传统模式困境（效率/误差/风险/合规，每项配数字，标注依据）
   - 素材来源：行业知识文件 + 联网搜索（政策/痛点）
   - 模式A处理：**必须重写**，替换为目标行业特有的人工检测痛点
   - **修改注意**：四个卡片的PPT内容和备注都要改；风险高卡片中的温度参数（医药700-800℃/浓硫酸）必须替换为目标行业对应参数（如食品550℃/样品碳化）；合规难卡片中的GMP/21 CFR需按行业调整（见0.8.5）

5. **政策背景** `[行业专属]` — 新规实施 + 监管加严 + 数智化转型，**每条政策标注来源**（发文部门/会议/日期）
   - 素材来源：行业标准表（最新发布/即将实施的标准）+ 本地标准库 + 联网搜索
   - 模式A处理：**必须重写**，替换为目标行业的监管政策和新标准；突出即将实施的新标准作为卖点
   - **修改注意**：这是备注遗漏最高发的页面——PPT三列卡片改了，但备注大段文字（新药典/集采/医药工业数智化/德勤制药QC调研）经常忘记改，必须完整重写备注；底部"全球趋势"数据可保留为通用实验室调研

### 第二幕 关于公司

8. **行业服务基础（客户墙）** `[半通用]` — 客户数量 + 典型客户图墙（logo墙，客户名按用户要求处理）
   - 素材来源：内置医药49家logo资产（`assets/logo-wall/`）+ 检测报告库（该行业已有报告的客户）+ 公司材料
   - 模式A处理：
     - **医药行业**：直接用内置49家logo资产，`refill_template.py` 一键填充模板
     - **其他行业**：**必须先询问用户提供49家客户名单**（企业全称+官网URL），然后按 SKILL.md 0.5节客户墙子流程，经6阶段（名单→抓取→SVG转PNG→视觉QA→标准化→生成PPT）制作新logo墙

## 页面设计要点

- 每幕有章节分隔页；每页一个核心结论做标题，正文短句列表，数据高亮。
- 连续两页避免相同骨架；数据类页用表格/对比，流程类页用流程图，产品页用实拍图。
- 政策/数据/来源必须标注出处；客户名按用户要求模糊化（如"某大型化学药企""华东某综合制药企业"）。
- 每页 `<note>` 写 3-5 句可直接照读的讲稿；结尾页深色背景收束 + 联系方式。
- 配色/字体/版式严格遵守 `brand-language.md`，换行业时视觉系统不变，只换内容与标准。
