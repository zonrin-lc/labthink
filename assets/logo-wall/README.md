# Logo资产说明

本目录用于存放客户墙logo资产。由于涉及商标权，仓库中不包含实际logo文件。

## 使用方法

1. 向管理员获取医药行业49家企业logo资产包（含logo图片、排序文件、模板PPT）
2. 将资产解压到本目录，结构如下：
   ```
   assets/logo-wall/
   ├── logos/          # 49家企业logo（PNG，白底/透明底彩色版）
   ├── template.pptx   # 客户墙模板PPT
   ├── order.txt       # 企业排序文件
   └── logo-index.xlsx # logo索引表
   ```
3. 其他行业需按SKILL.md 0.5节客户墙子流程自行抓取和制作

## 注意事项

- 企业logo涉及商标权，仅限内部使用，禁止公开分发
- 严格按名单顺序排列，不按颜色/大小/重要性重排
- 必须做视觉QA，自动化抓取经常返回错公司、不可见白标、裁切不全
